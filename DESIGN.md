## Brand & Style

This design system translates the rigorous precision of Swiss modernist typography and the polished industrial minimalism of Apple product showcases into an authoritative developer portfolio. Designed for a full-stack engineer crossing into artificial intelligence and machine learning, the aesthetic communicates intellectual depth, technical precision, and restraint.

### Visual Aesthetic & Philosophy
- **Modernist Discipline:** Structural clarity governed by meticulous grid alignment, negative space, and typographic hierarchy. Visual interest stems from contrast and layout tension rather than superfluous decoration.
- **Atmospheric Restraint:** A canvas dominated by low-saturation neutrals with architectural blue moments reserved exclusively for primary actions, states, and data signals.
- **Tactile Digital Craft:** High-density hairline micro-borders, razor-sharp edge transitions, and subtly diffused translucent blurs that reference physical paper stocks and precision-milled hardware.

## Typography

Typographic scale is structured around an editorial pairing: **Space Grotesk** serves headline roles with a calibrated negative tracking (`-0.03em` to `-0.04em`) to achieve the tight, modernist silhouette characteristic of Swiss design catalogues; **Inter** handles continuous reading and body copy with neutral optical clarity; **Geist** powers metadata, navigation, metric readouts, and UI badges.

### Typographic Rules
- Use `display-hero` exclusively for primary mastheads and introductory narrative thesis statements.
- `label-caps` must always be transformed to uppercase with tracking at `0.08em` for section indexes (e.g., `01 / SELECTED WORK`, `02 / RESEARCH & ARCHITECTURE`).
- Numerical statistics, system indicators, and commit tags use `label-code` with tabular figure settings (`font-variant-numeric: tabular-nums`).

## Layout & Spacing

The portfolio is structured on an asymmetric 12-column grid constrained to a maximum content width of `1240px`, prioritizing editorial breathing room.

### Layout Rhythm
- **Desktop (>= 1024px):** 12-column layout, `4rem` outer margin, `1.5rem` grid gutter. Key sections utilize an asymmetrical 4/8 column split (4 columns for sticky section index and project context, 8 columns for narrative documentation and interactive UI displays).
- **Tablet (768px - 1023px):** 8-column layout, `2.5rem` outer margin, `1.25rem` gutter. Side-by-side elements collapse to alternating full/half span containers.
- **Mobile (< 768px):** 4-column layout, `1.25rem` outer margin, `1rem` gutter. Sticky sidebars transform into inline headers with sticky compact category pills.
- **Vertical Spacing:** Section modules are partitioned by `space-3xl` (96px) in desktop, compressing to `space-2xl` (64px) on mobile viewports.

## Elevation & Depth

This system intentionally rejects heavy, multi-layered drop shadows in favor of a crisp architectural planar language rooted in hairline containment and high-fidelity surface fills.

### Surface Hierarchy
- **Base Layer (Ground):** Matte canvas texture (`#F7F7F5` / `#111111`) establishing the reading plane.
- **Card Tier (Structural Float):** Elevated through a solid planar fill (`#FFFFFF` / `#1B1B1B`) bounded by a continuous `1px` solid border (`#E8E8E5` / `#303030`).
- **Interactive Focus / Lift:** Hover states do not project deep drops. Instead, they produce a `1px` micro-translation (`translateY(-2px)`) accompanied by an ultra-subtle, diffused contact shadow:
  - Light mode: `0 8px 24px -4px rgba(23, 23, 23, 0.04), 0 2px 6px -1px rgba(23, 23, 23, 0.02)`
  - Dark mode: `0 8px 24px -4px rgba(0, 0, 0, 0.4), 0 2px 6px -1px rgba(0, 0, 0, 0.3)`
- **Header & Command Bar Overlay:** Translucent frosted veil using `backdrop-filter: blur(16px)` with `background: rgba(247, 247, 245, 0.82)` (light) or `rgba(17, 17, 17, 0.82)` (dark), anchored by a bottom `1px` border.

## Shapes

The geometric framework follows a restrained, semi-sharp curvature system (Soft / Level 1) to evoke engineering instruments and industrial product packaging.

### Radius Assignments
- **Base Elements (`0.25rem` / `4px`):** Tags, system badges, code blocks, tab triggers, and micro-inputs.
- **Cards & Canvas Modules (`0.5rem` / `8px`):** Project preview frames, modal dialogue boxes, and timeline containers.
- **Outer Device Shells (`0.75rem` / `12px`):** Realistic viewport frames simulating browser windows and hardware mocks.
- **Toggle Controls & Status Nodes:** Full rounded circular geometry (`9999px`) reserved strictly for status pings (e.g., active telemetry indicator) and theme toggle icons.

## Components

### Buttons
- **Primary:** Solid dark carbon (`#171717` in light, `#F5F5F5` in dark) with inverted high-contrast typography, `0.25rem` border radius, padding `0.625rem 1.25rem`. Transitions smoothly to a muted hover state (`opacity: 0.9`).
- **Secondary / Outline:** Transparent background, `1px` border (`#E8E8E5` / `#303030`), typography matching primary text color. Hover triggers border color shift to accent blue and an ultra-light tint fill.
- **Ghost:** Borderless, standard padding `0.5rem 0.75rem`, secondary text color, shifting to primary text on interaction.

### Badges & Filter Chips
- Rendered with `label-code` typography. Height locked to `24px` with horizontal padding `8px`.
- Architectural blue accents: `background: rgba(82, 109, 145, 0.08)`, border `1px solid rgba(82, 109, 145, 0.2)`, text color `#526D91` (light mode) / `#86A9D5` (dark mode).
- Neutral tags: Subtle grey background, `1px` hairline border, secondary text.

### Interactive Project Cards & Realistic Mockups
- **Outer Shell:** Surface container (`#FFFFFF` / `#1B1B1B`) bound by standard hairline borders.
- **Device Mock Header:** Simulated minimalist browser chrome featuring three mono-grey control dots (`6px` diameter, `#E8E8E5` / `#303030`) and a centered monospaced path string in `label-code`.
- **Canvas Display:** Aspect ratio locked to `16:10` for desktop views and `9:16` for mobile views, embedded inside a hairline bounding container with a `0.25rem` internal offset.

### Interactive Career & Research Timeline
- Linear vertical hairline (`1px` width, `#E8E8E5` / `#303030`) connecting node blocks.
- **Node Indicators:** `7px` square markers aligned to the centerline of the headline. Active/current roles feature an architectural blue square encased in a translucent pulsing ring.
- **Date Stamp:** Displayed via `label-code` pinned to the margin edge.

### Inputs & Code Terminal Blocks
- **Input Fields:** Flat background (`#FFFFFF` / `#1B1B1B`), `1px` border, padding `0.625rem 0.875rem`, placeholder text `#9E9E9C` / `#666666`. Focus state eliminates browser ring in favor of a crisp `1px` active carbon border.
- **Code Terminal:** Dedicated `#F0F0ED` (light) / `#151515` (dark) recessed panel with embedded syntax coloring tuned to harmonious architectural hues.
